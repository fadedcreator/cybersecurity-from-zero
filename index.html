Cloud & Container Security
Modern infrastructure runs in the cloud on containers. The attack surface is different from traditional servers — misconfiguration is the #1 cloud vulnerability, not software exploitation.
How Containers Work

Containers (Docker, Kubernetes) package applications with their dependencies in isolated processes. Unlike VMs, containers share the host OS kernel — making them lighter but with a different security boundary.

# Docker security issues to check docker ps # What's running? docker inspect [container] # Check for privileged mode, mounts # Dangerous: privileged container = nearly host escape docker run --privileged ... ← can escape to host # Dangerous: mounting host filesystem docker run -v /:/host ... ← attacker reads/writes host
Container Escape

A container escape lets an attacker break out of a container and access the host system. Common paths: privileged containers, exposed Docker sockets (/var/run/docker.sock mounted = game over), kernel vulnerabilities, dangerous capabilities (CAP_SYS_ADMIN).

  • Public S3 buckets: Misconfigured AWS S3 buckets have leaked terabytes of sensitive data from major companies

  • Exposed Kubernetes dashboard: Unauthenticated kubectl access = cluster compromise

Bug Bounty Hunting
Bug bounty programs pay you to find real vulnerabilities in real systems. It's how many security professionals earn while they learn — and how some make a full-time income.
How Bug Bounties Work

Companies publish scope (what you're allowed to test) and a reward table. You find a vulnerability, submit a detailed report, and if valid and in-scope, get paid. Payouts range from $50 for low-severity findings to $1M+ for critical vulnerabilities in major platforms.

Major Platforms
  • HackerOne — largest platform. Google, Uber, Twitter/X, GitHub all run programs here
  • Bugcrowd — enterprise-focused. Good variety of programs
  • Intigriti — European-focused, growing fast
  • Synack — invite-only, higher payouts, vetted researchers
  • Public programs directly — Google VRP, Apple Security Research, Microsoft MSRC
How to Start
1. Learn # PortSwigger Academy, TryHackMe, this curriculum 2. Tools # Burp Suite, ffuf, nuclei, amass for recon 3. Target # Start with less competitive programs (newer, smaller) 4.
